# Assets

Katalog na obrazy, ikony, ilustracje i inne pliki wykorzystywane przez frontend.
Pliki importowane z `src/assets` można dodawać bezpośrednio w komponentach lub
konfiguracji danych, np. `import portrait from '../assets/portrait.webp'`.

Warto grupować większe zbiory według rodzaju (`images/`, `icons/`) i używać
opisowych nazw plików. Zasoby publiczne, które muszą zachować stały adres URL,
można umieszczać w `public/`.
